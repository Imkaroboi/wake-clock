# Wake Clock

Keep your Mac and its display awake from the menu bar. Turn Keep Awake on indefinitely, set a countdown, or choose a time to stop. You can also schedule your Mac to sleep at a specific local time.

## Downloads

- [Download Wake Clock 1.2](https://github.com/Imkaroboi/wake-clock/releases/download/v1.2/Wake-Clock-1.2-macOS-arm64.zip) — the latest version, with an on/off switch.
- [Download Wake Clock 1.1](https://github.com/Imkaroboi/wake-clock/releases/download/v1.1/Wake-Clock-1.1-macOS-arm64.zip) — the original text menu control.

## Installation

Requires an Apple Silicon Mac running macOS 13 or later. Unzip the download, move **Wake Clock.app** to Applications, and open it. Click the coffee cup in the menu bar to access the controls. Choose **Open at Login** if you want the app to start when you sign in.

Both downloads are ad-hoc signed. If macOS asks for approval, review the app in System Settings → Privacy & Security. Each release includes a SHA-256 checksum for its ZIP.
